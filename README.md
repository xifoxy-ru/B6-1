# B6-1 IAM 정책 템플릿 준비

현재 작업 `B6-1-006`은 새 로컬 Git 기준선 준비다. 정책 JSON·검증 코드는 아직 구현하지 않았고, 이 저장소의 현재 파일은 README와 .gitignore뿐이다.

후속 승인 작업에서는 공식 AWS 문서를 조사하여 사용자가 직접 검토·붙여넣을 JSON 템플릿 3개를 준비할 계획이다.

- EC2 운영자: 서울 리전의 작은 단일 서버 실습에 필요한 VPC/EC2/SG 준비·실행·정리 권한.
- Budget 관리자: 예산 관리 권한을 운영자와 분리.
- 이메일 연락처 확인: 알림 연락처 생성·조회·활성화 권한을 별도 분리.

이 단계에서는 AWS 호출·로그인·현재 계정 검증을 하지 않았다. 실제 대상 계정·리소스·신원 상태는 알 수 없으며, 나중에 계정 placeholder와 기존 자원 참조를 사용자가 확인해야 한다. 정책을 연결하거나 권한을 부여하지 않았다. IAM Allow는 SCP의 명시적 Deny나 닫힌 계정 상태를 해결하지 못한다. SCP 해결·배포 가능·최소권한 적용 완료를 주장하지 않는다.

후속 템플릿도 검토용이며 실제 환경에서 미검증 상태로 표시한다. 운영자에 iam:*·전체 접근·PassRole을 기본으로 넣지 않고, Budget/연락처 작업과 분리할 계획이다. 생성된 계정별 정책은 rendered/ 또는 output/에만 보관하고 비밀정보와 함께 Git에서 제외한다. 의도한 원본 템플릿과 가벼운 검증 파일은 추적 대상으로 유지한다.

원격 Git·배포·비용 발생 작업은 수행하지 않았다. 원본 과제 자료는 이 저장소에 복사하지 않는다.
